# spaza.coop promotional website

Public promotional site for the spaza.coop initiative, covering wholesale sourcing, finance, devices and software, payments, and last-mile delivery.

Staging: https://spaza.forus.digital/

Website source and static assets: `spaza-site/dist/`.

Preview locally with `node spaza-site/serve.cjs` and visit http://127.0.0.1:4173/.

GitHub Actions publishes the static directory to GitHub Pages on pushes to `main`. See [project documentation](spaza-site/README.md) for sourcing and deployment details.

This first release is promotional. The full FORUS technology stack and transaction services are a subsequent phase.
